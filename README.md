# HAKYHM Official Website

Updated responsive static website package.

## What's updated
- Desktop layout is preserved.
- Mobile layout is redesigned for phones instead of simply shrinking the desktop layout.
- Mobile header has Share + Menu on the left and HAKYHM branding on the right.
- Hamburger opens a full-screen mobile navigation and changes to an X.
- Native mobile Share is supported when available, with clipboard fallback.
- Hero imagery stacks cleanly and preserves proportions.
- Music cards use a single-column mobile layout with larger touch targets.
- Tour events stack cleanly on smaller screens.
- Desktop hover/tilt effects are disabled on touch devices.
- Music catalog loading remains powered by the existing iTunes artist lookup.

## Publish with GitHub Pages
1. Upload the contents of this folder to the root of your repository.
2. Keep the `images` folder from your existing website alongside `index.html`.
3. Go to Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
